## What It Takes to Reach 20KB

Twenty kilobytes is a restrictive limit for detailed or high-resolution images. Output format, visual complexity, quality and pixel dimensions all affect whether the target can be reached.

## The 20KB Compression Route

1. Add an image and open the editor with a 20KB maximum.
2. Let the editor search JPEG quality first.
3. If needed, allow proportional dimension reduction and check the final result.

## Choose a Format for a Very Small File

JPEG works well for many photographs. WebP and AVIF provide alternative lossy output. The target-size control supports all three, so compare the visible result rather than assuming one format always wins.

## Read the Result, Not Just the Limit

Check the actual bytes, quality, width and height after processing. The result may be below 20KB, and a demanding source may require smaller dimensions than expected.

## Local Processing

The source image stays on the device while the browser tests quality and dimensions.

## FAQs

### How do I compress an image to 20KB?

Add the image, keep the 20KB target, let Vicoco search output settings, and download after checking quality and dimensions.

### Is 20KB an exact size or a maximum?

It is a maximum. A successful result can be smaller than 20KB.

### Why does a 20KB image look less detailed?

Reaching a very small limit can require lower quality, smaller pixel dimensions, or both, especially for detailed photographs.

### Can Vicoco resize the image automatically?

Yes. You can enable resize fallback so the editor can reduce dimensions if quality alone cannot meet 20KB.

### Can PNG use the automatic 20KB target?

The automatic target control supports JPEG, WebP and AVIF output. A PNG source can be converted to one of those formats.

### Can every image reach 20KB?

No result is guaranteed for every source and setting. Vicoco reports when the target was not met.

### Are images uploaded to a server?

No. Compression runs locally in the browser.
