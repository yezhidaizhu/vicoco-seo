## FAQs

### How do I compress an image to 500KB?

Add the image, keep the 500KB target, run the calculation, and download after checking the actual file size.

### Will a 500KB result be exactly 500KB?

No. The setting is a maximum, so the result can be smaller.

### Does Vicoco lower dimensions automatically?

Only when the target cannot be reached through quality adjustment and resize fallback is enabled.

### Can I compress JPG, PNG, WebP or AVIF input?

You can add browser-readable images and choose JPEG, WebP or AVIF output for the automatic target.

### Which format creates the best 500KB image?

There is no universal winner. Compare the formats using the actual source and choose the result that fits your compatibility and quality needs.

### Can I apply the settings to several images?

Yes, but reused settings do not guarantee that every source will be under 500KB because image content differs.

### Are files uploaded during compression?

No. Processing is local to the browser.
