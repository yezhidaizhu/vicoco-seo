## Compress JPG to 100KB or Less

The preset starts with JPEG output, making it suitable for the common JPG-to-100KB task. You can switch to WebP or AVIF and run the target again when another output format fits your workflow.

## Control the 100KB Result

- Target limit: the result aims to stay at or below 100KB.
- Quality search: Vicoco keeps the highest tested quality under the limit.
- Resize fallback: dimensions can be reduced when quality alone is insufficient.

## Three Steps to a 100KB Image

1. Add a JPG or another browser-readable image.
2. Run the preselected 100KB target and compare the result.
3. Download after confirming file size, quality and dimensions.

## Verify the Generated File

Use the actual file-size readout rather than estimating from the quality value. Image content and dimensions mean the same quality can create different file sizes.

## Local Processing

Target calculation and encoding occur on the device, without sending the source image to a processing server.

## FAQs

### How do I compress a JPG file to 100KB?

Add the JPG, keep the 100KB target, let Vicoco test the output, and download after confirming the reported size.

### Will the JPG be exactly 100KB?

No. The target is a maximum, so the file can be smaller than 100KB.

### Does the tool preserve the original dimensions?

It preserves dimensions when quality adjustment is enough. If resize fallback is needed, the result reports the reduced width and height.

### Can I use WebP or AVIF for a 100KB result?

Yes. The target-size control supports JPEG, WebP and AVIF output.

### Why do two images need different quality settings?

Image detail, noise, colours and dimensions affect compressed size, so each source can require a different quality.

### Can I process a folder after testing one image?

Yes. Review the active image first, then use its resulting format, quality and resize settings for the queue. Queue files are not guaranteed to have identical sizes.

### Does Vicoco upload the JPG?

No. Processing runs locally in the browser.
