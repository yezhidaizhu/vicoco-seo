## How the 50KB Target Works

Vicoco tests output quality for JPEG, WebP or AVIF and keeps the highest tested result that fits the 50KB maximum. If quality alone cannot reach the limit, the enabled resize fallback can reduce pixel dimensions and try again.

## Compress an Image to 50KB

1. Add the image you need to reduce.
2. Review the preselected 50KB maximum and output format.
3. Let Vicoco test the image, then inspect the result before downloading.

## Quality Before Dimensions

The editor first searches output quality. Pixel dimensions are reduced only when the 50KB target cannot be met through quality adjustment alone and resize fallback is enabled.

## Check Whether 50KB Was Reached

The result reports the actual file size, chosen quality, output width and height, and whether resizing was used. A complex image may not reach 50KB if resizing is disabled or browser limits interrupt processing.

## Local Processing

Image decoding, target-size testing, resizing and encoding run in the browser. Source images are not sent to a Vicoco processing server.

## FAQs

### How can I reduce an image size online to 50KB?

Add the image, keep the 50KB target, choose JPEG, WebP or AVIF output, and review the generated result before downloading.

### Does the result stay under 50KB exactly?

The tool treats 50KB as a maximum, not an exact file size. The result can be smaller than 50KB.

### Will compressing to 50KB reduce image dimensions?

Only when quality adjustment cannot meet the target and resize fallback is enabled. The result shows whether resizing was used.

### Which formats support the 50KB target?

The automatic target-size control supports JPEG, WebP and AVIF output.

### Can I compress several images to 50KB at once?

The target-size search runs for the active image. After reviewing its generated settings, you can process the queue with those settings, but different images may produce different file sizes.

### What happens if the image cannot reach 50KB?

Vicoco reports that the target was not met and shows the smallest generated result so you can allow resizing or adjust the image further.

### Are images uploaded while compressing to 50KB?

No. Processing runs locally in the browser.
