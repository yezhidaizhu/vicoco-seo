## PNG Palette, Dithering and Alpha Transparency

Use fewer colours when the image can tolerate palette reduction, tune dithering to balance colour transitions against texture, and export as PNG to retain alpha transparency.

## Reduce Transparent PNG File Size

Palette size, pixel dimensions, detailed textures and complex transparent edges can all influence PNG file size. Apply one palette, dithering and dimension configuration to the complete queue when the images share the same needs.

## FAQs

### How do I compress a transparent PNG?

Add the PNG, reduce palette colours or dimensions, adjust dithering, inspect transparent areas, and download the PNG result.

### Does PNG compression remove transparency?

Not when you export as PNG. The result still supports alpha transparency, which you can verify in the preview.

### Can I compress a transparent PNG without losing quality?

PNG encoding is lossless, but palette reduction changes the available colours. Use the comparison preview and keep more colours when exact appearance matters.

### Why is my transparent PNG file large?

Large pixel dimensions, many colours, detailed textures and complex transparent edges can all increase PNG file size.

### Can I compress several transparent PNGs at once?

Yes. Add multiple PNG files or a folder, apply shared settings, and download the results in a ZIP.

### Can I convert a transparent PNG to WebP?

Yes. Select WebP output and compare transparency and file size before downloading.

### Are transparent PNG files uploaded to Vicoco?

No. Processing runs locally in the browser.
