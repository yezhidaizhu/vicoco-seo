## JPG and JPEG Use the Same Image Format

`.jpg` and `.jpeg` are filename extensions for JPEG images. This page provides a `.jpeg` output filename while letting you review the encoded image instead of only renaming the source file.

## How to Convert JPG to JPEG

1. Add one or more JPEG images with `.jpg` or `.jpeg` filenames.
2. Review JPEG quality and optional dimensions.
3. Compare the result, then download a file ending in `.jpeg`.

## Re-encoding Affects the Result

The converter encodes the image again. Changing JPEG quality or dimensions can change file size and visual detail, so compare the output before downloading.

## Batch `.jpeg` Output

Add a folder or several JPG files, reuse the selected JPEG settings and download the processed `.jpeg` files in one ZIP. Non-JPEG inputs are rejected by this page preset.

## Local Processing

JPEG validation, decoding and encoding run in the browser without sending source files to a Vicoco processing server.

## FAQs

### How do I convert JPG to JPEG?

Add the JPG, review the JPEG settings, and download the processed result with a `.jpeg` filename.

### Are JPG and JPEG the same format?

Yes. Both extensions commonly identify JPEG image data. The difference here is the filename extension used for output.

### Does changing JPG to JPEG improve quality?

No. Changing the extension does not create missing detail, and re-encoding can alter quality depending on the selected settings.

### Does the converter only rename the file?

No. Vicoco decodes and re-encodes the image, then names the output with `.jpeg`.

### Can I convert multiple JPG files to JPEG?

Yes. Add several JPEG files or a folder, apply shared settings and download a ZIP containing `.jpeg` files.

### Can I change JPEG quality while converting?

Yes. Adjust quality and compare file size and visual detail before export.

### Are JPG files uploaded to a server?

No. Processing runs locally in the browser.
