## Image File Size and Pixel Dimensions

### Image File Size

File size is the storage used by the image, shown in bytes, KB, or MB. Format, image content, dimensions, and compression settings all affect it.

### Image Width and Height

Pixel dimensions describe the image width and height, such as 1920 × 1080. Large dimensions can increase file size but are not the same measurement.

### Image Format

The checker identifies JPEG, PNG, WebP, AVIF, GIF, SVG, and other browser-readable image types.

## FAQs

### How do I check an image's file size online?

Add the image to Vicoco and read its file size in the results below the upload area.

### How do I check an image's width and height?

Add the image to the checker. Its pixel width and height appear in the inline file details.

### What is the difference between image file size and dimensions?

File size measures storage in KB or MB. Dimensions measure pixel width and height. They influence each other but are not interchangeable.

### Does the image size checker compress my image?

Not automatically. The checker only reads file information until you choose `To compress` to open the listed images in the Vicoco compressor.

### Which image details does the checker show?

It shows the filename, detected format, file size, pixel width and height, aspect ratio, and a local preview.

### Can I check image sizes on iPhone or Windows?

Yes. Open Vicoco in a modern browser, choose the image, and read its file size and dimensions without installing software.

### Are images uploaded while I check them?

No. File inspection and processing run locally in the browser.
