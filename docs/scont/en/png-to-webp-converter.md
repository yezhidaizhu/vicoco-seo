## WebP Quality, Transparency, and File Size

### Lossy WebP for Smaller Files

Use adjustable lossy quality for photographs and detailed graphics when reducing file size is the priority.

### Lossless WebP for Exact Pixels

Use lossless WebP when every decoded pixel must be preserved. Lossless output can be larger than a well-tuned lossy result.

### WebP Transparency

WebP supports transparency. Compare the converted result before downloading when the source PNG uses transparent areas.

## FAQs

### How do I convert PNG to WebP?

Add a PNG, select WebP as the output format, choose quality or lossless mode, and download the converted `.webp` file.

### Does converting PNG to WebP reduce file size?

Often yes, but the result depends on image content and settings. Compare the displayed file sizes before downloading.

### Can WebP keep PNG transparency?

Yes. WebP supports an alpha channel, so transparent areas can remain transparent after conversion.

### Which WebP compression is better, lossless or lossy?

Lossless preserves exact decoded pixels. Lossy usually creates smaller files. Use the preview to choose the appropriate balance.

### Can I convert multiple PNG files at once?

Yes. Add multiple PNG files or a folder, apply one WebP configuration, and download all results in a ZIP.

### Are my PNG files uploaded to a server?

No. Conversion runs locally in the browser, so source files stay on your device.

### Does ZIP make converted WebP files smaller?

Usually not by much because WebP is already compressed. ZIP is mainly used to download multiple converted files together.
