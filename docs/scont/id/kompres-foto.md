## Cara Kompres Foto Online

### 1. Pilih Foto yang Ingin Dikompres

Pilih satu atau beberapa foto, tambahkan satu folder, tarik file ke halaman, atau tempel foto dari clipboard.

### 2. Atur Kualitas dan Ukuran Foto

Pilih format keluaran, sesuaikan kualitas, dan ubah lebar atau tinggi jika diperlukan. Pratinjau menampilkan hasil dan ukuran file sebelum diunduh.

### 3. Unduh Foto Hasil Kompresi

Unduh satu foto secara langsung. Untuk banyak foto, gunakan pengaturan yang sama pada seluruh antrean dan unduh hasilnya dalam satu file ZIP.

## Kompres Foto Tanpa Upload ke Server

Vicoco memproses foto secara lokal di browser. Foto sumber tidak dikirim ke server pemrosesan, sehingga file tetap berada di perangkat Anda.

- Tidak perlu membuat akun
- Tidak ada unggahan ke server pemrosesan
- Pemrosesan dilakukan di browser
- Dapat digunakan di komputer dan ponsel dengan browser modern

## Kompres Banyak Foto Sekaligus

Tambahkan beberapa foto atau satu folder, lalu gunakan format, kualitas, dan ukuran yang sama untuk seluruh antrean. Setelah pemrosesan selesai, semua hasil dapat diunduh dalam satu file ZIP.

Nama file hasil dapat menggunakan nama asli, nomor urut, lebar, atau tinggi gambar.

## Format Output untuk Kompres Foto

### Foto JPG

Untuk kompres JPG, sesuaikan kualitas agar ukuran file berkurang tanpa menghilangkan terlalu banyak detail foto.

### Gambar PNG

Untuk kompres PNG, optimalkan jumlah warna dan tetap pertahankan transparansi gambar.

### Format WebP

Konversi foto ke WebP untuk menghasilkan file yang lebih kecil dan sesuai untuk website.

### Format AVIF

Konversi foto ke AVIF untuk kompresi dengan efisiensi tinggi.

## Memperkecil Ukuran Foto dengan Pratinjau

## FAQs

### Bagaimana cara kerja kompresi gambar?

Kompresi gambar mengurangi jumlah data dalam file. Kompresi lossy membuang sebagian detail yang kurang terlihat, sedangkan kompresi lossless menyusun data dengan lebih efisien tanpa membuang informasi gambar.

### Bagaimana cara mengompres foto untuk website tanpa banyak mengurangi kualitas?

Pilih WebP, AVIF, atau JPEG, lalu turunkan kualitas secara bertahap sambil memeriksa pratinjau. Jika dimensi foto lebih besar dari kebutuhan website, kecilkan lebar dan tingginya untuk mengurangi ukuran file lebih lanjut.

### Bagaimana cara mengurangi ukuran foto di iPhone?

Buka Vicoco melalui browser di iPhone, pilih foto, atur format, kualitas, atau dimensi, lalu unduh hasilnya. Pemrosesan dilakukan langsung di browser.

### Bagaimana cara mengurangi ukuran foto di Windows?

Buka Vicoco di browser Windows, tambahkan foto, pilih kualitas dan ukuran yang diperlukan, lalu unduh foto hasil kompresi.

### Bisakah saya mengurangi ukuran banyak foto sekaligus di macOS?

Ya. Tambahkan beberapa foto atau satu folder, gunakan pengaturan yang sama untuk seluruh antrean, lalu unduh semua hasil dalam satu file ZIP.

### Apakah ZIP mengurangi ukuran foto?

Biasanya tidak banyak untuk JPG, PNG, WebP, atau AVIF karena format tersebut sudah menggunakan kompresi. Di Vicoco, ZIP terutama digunakan untuk mengunduh banyak hasil sekaligus; pengurangan ukuran berasal dari pengaturan kompresi gambar.

### Apakah foto saya diunggah ke server?

Tidak. Pemrosesan gambar dilakukan secara lokal di browser, sehingga foto sumber tidak dikirim ke server pemrosesan.

### Format foto apa yang dapat dikompres?

Vicoco menerima format gambar umum seperti JPG, PNG, WebP, AVIF, dan SVG. Hasil dapat diekspor sebagai JPG, PNG, WebP, atau AVIF.

### Apakah Vicoco gratis?

Ya. Vicoco dapat digunakan gratis untuk mengompres dan mengonversi foto tanpa membuat akun.
