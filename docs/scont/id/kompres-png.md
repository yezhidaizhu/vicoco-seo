## Warna, Transparansi, dan Ukuran PNG

### Palet Warna PNG

Jumlah warna yang lebih kecil dapat mengurangi file pada ilustrasi, ikon, dan tangkapan layar.

### Transparansi PNG

PNG mendukung area transparan. Periksa hasilnya di pratinjau sebelum mengunduh.

### Dimensi dan Ukuran File PNG

Mengurangi lebar dan tinggi gambar yang terlalu besar dapat membantu mengecilkan file lebih lanjut.

## FAQs

### Bagaimana cara mengecilkan ukuran PNG?

Kurangi jumlah warna, atur dithering, dan kecilkan dimensi jika gambar lebih besar dari kebutuhan.

### Apakah kompres PNG mempertahankan transparansi?

Ya. Ekspor PNG tetap mendukung transparansi; periksa pratinjau untuk memastikan hasilnya.

### Apakah PNG menggunakan kompresi lossless?

PNG menyimpan piksel secara lossless, tetapi pengurangan palet warna mengubah jumlah warna sebelum pengodean.

### Bisakah banyak PNG dikompres sekaligus?

Ya. Tambahkan beberapa PNG atau folder dan unduh hasil dalam ZIP.

### Apakah ZIP membuat PNG jauh lebih kecil?

Biasanya tidak banyak karena PNG sudah dikompres. ZIP terutama digunakan untuk mengunduh banyak hasil.

### Apakah PNG diunggah ke server?

Tidak. Semua pemrosesan berlangsung lokal di browser.

### Bisakah PNG dikonversi ke WebP?

Ya. Pilih WebP sebagai format output jika Anda ingin membandingkan alternatif yang lebih efisien.
