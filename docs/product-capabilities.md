# Vicoco 产品功能快照

本文件用于约束 SEO 页面功能声明。功能仓库中的 `docs/implemented-features.md` 是权威清单；本文件应与其同步。

## 已实现

| 功能                           | 状态 | SEO 可用描述                                                                                               |
| ------------------------------ | :--: | ---------------------------------------------------------------------------------------------------------- |
| 单张与多张图片选择             |  ✓   | 选择一张或多张图片进行处理                                                                                 |
| 文件夹选择和递归拖放           |  ✓   | 添加整个文件夹中的图片                                                                                     |
| 剪贴板粘贴                     |  ✓   | 从剪贴板添加图片                                                                                           |
| SEO 页面到编辑器的本地交接     |  ✓   | 图片通过浏览器 IndexedDB 交接，不上传服务器；实现见 [UploadHero.astro](../src/components/UploadHero.astro) |
| 批量图片队列                   |  ✓   | 为多张图片复用同一套输出设置                                                                               |
| JPEG、PNG、WebP、AVIF 稳定输出 |  ✓   | 压缩或转换为常用 Web 图片格式                                                                              |
| PNG 转 WebP                    |  ✓   | 读取 PNG 并导出 `.webp`                                                                                    |
| JPEG 与 PNG 压缩               |  ✓   | 使用对应编码器调整压缩设置                                                                                 |
| 自定义像素宽高                 |  ✓   | 缩小、放大或拉伸图片尺寸                                                                                   |
| 调色板缩减                     |  ✓   | 减少颜色数量并调整抖动                                                                                     |
| 90 度旋转                      |  ✓   | 在预览中旋转图片                                                                                           |
| 双图对比与缩放                 |  ✓   | 比较原图和处理结果                                                                                         |
| 文件大小与尺寸显示             |  ✓   | 查看输入、输出文件大小和像素尺寸                                                                           |
| SEO 图片信息内联列表           |  ✓   | 在上传区下显示本地预览、格式、文件大小、像素尺寸和长宽比；支持追加、删除、清空及整批转入压缩编辑器           |
| 单图下载                       |  ✓   | 下载当前处理结果                                                                                           |
| 自动压缩到指定大小             |  ✓   | 为 JPEG、WebP 或 AVIF 单次计算普通 Quality/Resize 参数；后续处理与手动设置一致                             |
| 批量 ZIP 下载                  |  ✓   | 处理队列并下载 ZIP                                                                                         |
| 批量文件命名                   |  ✓   | 使用名称、序号、宽度和高度变量命名                                                                         |
| 压缩设置预设                   |  ✓   | 保存和复用格式、质量、尺寸及调色板设置                                                                     |
| 本地浏览器处理                 |  ✓   | 编解码在浏览器中执行，图片不上传处理服务器                                                                 |
| PWA 安装和系统分享入口         |  ✓   | 可安装，并可从系统分享图片进入应用                                                                         |

编码器还包含 GIF、JPEG XL、QOI 和 WebP v2。JPEG XL 标记为 beta，WebP v2 标记为 unstable，不应作为默认 SEO 功能声明。
