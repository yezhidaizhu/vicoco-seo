# SEO 页面内链规划

## 规则

- Footer 的“相关工具”包含首页入口，整组最多 5 个链接。
- 每页配置 2–4 个相关页面；同语言、同格式、同任务优先。
- 单语言页面不足时，连接功能最接近的其他语言页面，避免孤立页面。
- 未发布页面不提前添加链接；页面发布、改名或删除时同步更新本表。
- 正文只添加真正有帮助的描述性链接，不复制 Footer 链接凑数量。
